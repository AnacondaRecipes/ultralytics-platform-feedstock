Installing ultralytics-platform
==================

Installing `ultralytics-platform` from the main channel can be achieved by:

```
conda install ultralytics-platform
```

It is possible to list all of the versions of `ultralytics-platform` available on your platform with `conda`:

```
conda search ultralytics-platform
```
